# Table 6　Baseline 设计表

来源：`METHOD_PLAN.md` 第 6.1 节。不推荐设定：仅用随机预测（太弱）、未经时间对齐的全样本回归（高估预测力）、未经说明的闭源模型分数（复现性不足）。见 6.3 节。

| Baseline | 作用 | 选择理由 | 实现难度 |
|------|------|------|------|
| 无文本预测模型 | 只用市场、宏观、滞后行业收益等控制变量预测行业收益 | 判断文本情绪是否有增量信息，而不是只跟随机猜测比 | 低 |
| 行业历史均值 / 上一期收益 | 简单可复现的朴素预测 | 检验模型是否至少优于时间序列惯性 | 低 |
| 市场模型事件研究 | 用市场收益作为正常收益基准 | 事件研究的基础设定，结果易解释 | 低 |
| 词典法情绪 | 作为 LLM 评分的对照 | 工作区文献显示词典法成熟、成本低、可复现 | 低到中 |
| 中性情绪组 | 将情绪分为高、中、低三组 | 避免只用二分法导致信息损失 | 低 |
