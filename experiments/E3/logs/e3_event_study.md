## 4. 方法

- 估计窗：事件前 120 个交易日（t-120 至 t-1）；稳健性另用 90 / 180 / 250。
- 事件窗：[0,+1]、[0,+3]、[0,+5]、[0,+10]。
- 市场模型：`R_i = alpha + beta * R_m + eps`，估计窗 OLS，正常收益 `alpha + beta * R_m`；同一事件的所有行业共用同一估计窗长度。
- 均值调整模型：正常收益 = 估计窗行业收益均值。
- 超额市场模型：行业与市场收益均减 2 年期国债日收益（无风险利率补充模型）。
- AR = 实际收益 - 正常收益；CAR = 事件窗 AR 之和。
- 期层面 CAR：每个事件期对可用行业 CAR 等权平均；t 值、符号检验、Bootstrap CI 均在期层面计算。
- 行业组 CAR：先对组内行业按期等权平均，再对期做统计；组间差异用 Welch t + Bootstrap CI。
- 组间差异：高组期均值 - 低组期均值，Welch t 检验 + Bootstrap CI。
- 污染检查：每个事件最宽事件窗 [0,+10] 与污染清单区间重叠即标记。
