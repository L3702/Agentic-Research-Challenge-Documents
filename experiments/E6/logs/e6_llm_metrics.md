# E6 LLM 与词典情绪比较实验日志

## 1. 实验目的与假设

- 检验 H4：在相同样本、相同划分、相同控制变量下，LLM 情绪得分是否比词典法有更多增量信息。
- 对照：词典模型、LLM 模型、词典 + LLM 联合模型。

## 2. 固定口径

- LLM 模型：`qwen3.8-27b`；Prompt 版本：`v1`；温度：`0.0`。
- 面板与划分完全复用 E4：训练 2001Q2–2015Q4，验证 2016Q1–2020Q4，测试 2021Q1–2026Q3。
- 情绪模型设定：Baseline 控制 + `sentiment_z × sent_beta_z`；联合模型同时放入词典与 LLM 的情绪暴露交互项。
- LLM 得分文件：`experiments/E6/e6_llm_scores.csv`；原始 JSON 与成本见 `logs/e6_llm_prompt_and_cost.md`。

## 7. 结论

测试集上 LLM 模型 IC=0.0733、OOS R²=-0.6561、MAE=0.09004，词典模型 IC=-0.0169、OOS R²=-0.6041、MAE=0.08734；联合模型中 LLM 系数=-0.02716（NW p=0.6842）。LLM 未同时优于词典且增量系数不显著，H4 未获支持。

## 8. 局限

- LLM 模型、Prompt 与温度固定，但模型提供方后续可能更新底层权重；本报告记录模型名与调用时间。
- 人工抽检为单评分人预注册样本，未达到 E1 指南的双人独立评分要求。
- 季度样本约 100 期，横截面约 16–31 个行业，增量检验统计功效有限。
