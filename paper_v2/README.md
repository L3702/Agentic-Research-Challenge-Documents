# 论文修订稿 v2.0

主稿：`main.tex`。成品：`main.pdf`。日期：2026-11-20。

## 范围与文件

本稿根据 `paper_v1/论文修改意见.md` 对 v1.0 定向修订，保留六章结构、中英文摘要、自动目录、图表清单、参考文献及结果追溯附录。逐项处理情况见 `修改说明.md`。作者、学院、队名及指导教师沿用初稿信息。

- `introduction.tex`：绪论及文献综述。
- `methods.tex`：假设、数据、词典评分和事件研究。
- `models.tex`：预测、面板、异质性、LLM、组合及进一步分析。
- `conclusion.tex`：结论、文献对话、局限及可用性声明。
- `appendix.tex`：结果追溯。
- `literature.bib`、`methods.bib`：正文实际引用的 26 条题录。
- `figures/`：修订稿实际使用的 6 个图件及输入哈希清单，仅保留新版组合 PDF。
- `prepare_figures.py`：对研究框架、事件研究和风险收益图制作排版副本；以 E1 的 103 期 NTUSD 词频得分和覆盖率重绘情绪图，以 E5 原始斜率和区间重绘森林图，以 E7 完整输出重绘组合净值图。实验估计值保持原样。
- `qa.py`：提取 PDF 文本、生成缩略图，检查引文键、图表与公式交叉引用、重复标签及图件输入哈希，输出写入已忽略的 `qa/`。`--sources` 可预览全部 6 个实际图件，支持 PNG 和 PDF。

## 编译

需要 XeLaTeX、Biber、`ctex`、`biblatex` 及 `biblatex-gb7714-2015` 宏包中的 **`gb7714-2025`** 样式。宏包名称中的 2015 是分发包名称；主稿实际加载 2025 版顺序编码制样式。当前实测样式版本为 2026-06-10 v1.1x。正文只编入实际引用的文献，未查到 DOI 的中文论文不补造 DOI。

```powershell
cd D:\Codex\Agentic_Research_Challenge\paper_v2
.\build.ps1
python qa.py
python qa.py --sources
```

Biber 在当前机器的中文用户临时目录中报错，脚本只为本次编译设置英文临时目录，结束后还原进程环境。可用 `-BiberTemp 'D:\latex-temp'` 自定义缓存路径。重新生成论文专用插图时运行 `python prepare_figures.py`，再编译。

## 保留的实证边界

1. 行业起始批次按行情明细写为 16/12/3，合计 31。大纲中 2014 年起始行业的“14”未沿用。
2. E4/E6 保留为旧收益窗口下的回溯比较。E7 仅后移持有期，E8 另外重估了发布后首个完整季度的模型，并检查历史标签已实现约束。E8 的严格配对结果进入第五章和结论。
3. 共同情绪与单季截距/时间固定效应的识别问题、样本外 R² 的事后截面均值分母均明示。
4. E3 的八项展示检验单独列 BH/Holm 结果，并与 E8 的检验族区分。负向高减低差异不表述为支持正向假设。
5. E9 用逐响应审计区分 HTTP 429 限流与解析失败，不将全部失败归因于温度或模型能力。
6. 当前 E1 表已登记三位评分人及 15 期分值，每期只有一份评分，均标记为 completed。评分日期、耗时、独立双评及重测记录仍缺失，因此 H1 只按暂定数值判据获初步、部分支持。E6 临时评分参照单独归档。
7. E7 已披露回归因变量为多空收益再减无风险收益，故不将其截距解释为标准零成本多空 alpha。
8. 收益窗口对齐内容以 LaTeX 表格呈现，修订稿共 6 图、8 表，图表及公式均有正文引用。文本使用“原口径”和“严格口径”区分收益窗口；E7 只后移持有期，E8 另外施加历史收益标签可用的训练约束。
