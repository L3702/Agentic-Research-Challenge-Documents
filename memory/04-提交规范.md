# 提交规范

## Research Package 九项提交物

| # | 材料 | 说明 |
|---|------|------|
| 1 | 论文原型 PDF | 研究论文原型，含摘要、方法、结果与讨论 |
| 2 | 代码仓库 | 可复现代码，建议提供 Git 仓库地址或压缩包 |
| 3 | 数据来源说明 | 数据获取方式、许可与脱敏说明 |
| 4 | 实验证据 | 实验运行结果、指标与可视化证据 |
| 5 | 文献引用核验表 | 引用文献清单与核验情况 |
| 6 | Agent 使用日志 | AI Agent 工具使用过程日志 |
| 7 | 可复现说明 | 复现步骤、环境依赖与运行说明 |
| 8 | 人机分工声明 | 人与 AI 各自完成工作的声明 |
| 9 | 答辩 PPT | 5 分钟答辩演示材料 |

## 提交规则

- 九类提交物中，**代码仓库允许填写外链**（如 Git 仓库地址）；其余材料支持站内上传文件
- 同一类型重复提交自动记为**更高版本号**，保留版本历史
- 上传文件需符合类型与大小限制，**禁止上传可执行文件**
- 上传成功后可查看提交时间与版本
- 提交截止后材料进入**冻结状态（只读）**，冻结时间以组委会正式通知为准

## 可信科研原则

- **可核验**：每个结论都有数据、代码或过程证据支撑；引用文献需附核验表
- **可复现**：提供运行环境、步骤说明，他人可复现主要结果
- **人机分工透明**：声明人与 AI 各自完成的工作，符合学术诚信要求
- 赛事不承诺「7 天发表论文」；提交质量与证据完整度是评审重点

## 团队需要完成的时间线

1. 注册并组建 2 至 4 人队伍
2. 提交选题备案（Day 1）
3. 提交过程检查点（Day 3）
4. 按九项清单逐项提交（Day 7）
