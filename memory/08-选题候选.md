## 候选题目

### 候选 1：政策文本情绪与 A 股行业收益

- **科学问题**：央行货币政策执行报告（MPR）的文本情绪与措辞变化，是否对 A 股行业收益有预测力？
- **数据**：央行官网 MPR（2002 年至今，季度频率）；申万一级行业指数日行情（akshare）
- **方法**：文本情绪度量（词典法 + 主题模型）+ 事件研究法 / 面板回归 / 机器学习预测
- **最低验证**：样本外预测 R²；情绪因子多空组合收益；稳健性（不同词典）
- **创新点**：把货币政策文本的「措辞」与行业轮动结合，构建文本因子
- **风险**：季度频率样本量有限；情绪度量存在主观性
- **7 天可行性**：高

### 候选 2：上市公司年报文本与股价崩盘风险

- **科学问题**：年报文本特征（可读性、语气、相似度）是否预示股价崩盘风险？
- **数据**：巨潮资讯网年报 PDF；个股行情（akshare）
- **方法**：PDF 文本提取 + 文本指标构建 + 崩盘风险指标（NCSKEW / DUVOL）+ 面板回归
- **最低验证**：文本指标对崩盘风险的预测力；稳健性（不同指标）
- **创新点**：文本特征与尾部风险的关联
- **优势**：与既有研究能力（PDF 解析、证据核验）高度契合
- **风险**：PDF 处理工作量大；样本选择偏差
- **7 天可行性**：中高

### 候选 3：LLM 情绪指数构建与资产定价：LLM 与词典法对比

- **科学问题**：用大语言模型（LLM）提取的财经文本情绪，是否比传统词典法更能预测 A 股收益？
- **数据**：财经新闻 / 政策文本；行业指数行情
- **方法**：LLM 批量情绪标注（Agent 工作流）+ 词典法对比 + 预测回归 + 多空组合
- **最低验证**：样本外 IC / IR；LLM 与词典法预测力对比
- **创新点**：LLM 作为研究工具的系统性评估，贴合「智能体驱动」主题
- **风险**：新闻数据获取；LLM 标注成本与可复现性
- **7 天可行性**：中高

### 候选 4：ESG 评级分歧与股价崩盘风险

- **科学问题**：ESG 评级机构之间的分歧（rating divergence）是否加剧股价崩盘风险？
- **数据**：ESG 评级数据（CNRDS / Wind / 华证）；个股行情
- **方法**：面板回归 + 崩盘风险指标
- **创新点**：ESG 分歧是前沿话题
- **风险**：数据获取可能受限，7 天内未必拿得到
- **7 天可行性**：中低

### 候选 5：政策不确定性（EPU）与 A 股行业轮动

- **科学问题**：中国 EPU 指数是否可用于行业轮动配置？
- **数据**：EPU 指数（policyuncertainty.com）；申万行业指数
- **方法**：区制转换模型、时变参数、机器学习
- **风险**：EPU 指数本身由新闻构建，创新空间有限
- **7 天可行性**：高

### 候选 6：社交媒体情绪与个股崩盘风险

- **科学问题**：投资者社交媒体情绪是否预示个股崩盘风险？
- **数据**：东方财富股吧 / 雪球帖子（爬取）；个股行情
- **方法**：文本情感 + 崩盘风险指标
- **风险**：爬取合规与数据清洗工作量大；7 天紧张
- **7 天可行性**：中

## 推荐

**主线：候选 1 或候选 2**（数据最干净、与现有能力最契合、7 天最稳）

**创新点：嵌入候选 3 的方法**（用 LLM 做文本标注，与词典法对比，突出 Agentic 工作流）

理由：

- 评分维度含「Agentic 工作流」与「创新性」，LLM 标注对比能同时命中
- 数据全部公开可得，不依赖机构账号
- 与既有的文档解析、证据核验能力衔接顺滑
