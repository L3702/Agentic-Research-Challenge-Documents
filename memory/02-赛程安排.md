# 赛程安排

## 时间轴

| 阶段 | 时间 | 内容 |
|------|------|------|
| 报名 | 2026-10-19 至 2026-11-08 | 宣传报名，不限额 |
| 赛前培训 | 2026-11-09 至 2026-11-15 | 选题、研究方法、Agent 工具与提交规范培训 |
| 正式比赛 | 2026-11-16 至 2026-11-22 | 连续 7 天科研创造挑战 |

## 赛前阶段

宣传报名 → 赛前培训（Agent 使用）→ 6 小时内部测试

## 正式比赛 7 天流程

| 日期 | 阶段 | 任务 |
|------|------|------|
| Day 1 · 11-16 | 组队与选题备案 | 完成组队与 Day 1 选题备案 |
| Day 2 · 11-17 | 数据与研究方法 | 确定数据来源、baseline 与方法 |
| Day 3 · 11-18 | 过程检查点 | 提交中期 Checkpoint：代码 + baseline + Agent 日志 |
| Day 4 · 11-19 | 实验与 Agent 迭代 | 跑通实验证据，迭代 Agent 工作流 |
| Day 5 · 11-20 | 论文原型 | 完成论文原型初稿 |
| Day 6 · 11-21 | 可复现与核验 | 可复现说明、引用核验、人机分工声明 |
| Day 7 · 11-22 | Research Package 提交 | 提交九项材料与答辩材料 |

> 具体时间节点、检查点要求以正式赛程通知为准。

## 完整流程

1. **注册与组队**：队员用手机号或邮箱注册（默认角色学生）；队长创建队伍，填写队名、组别与赛道，邀请 2 至 4 名队员
2. **选题备案（Day 1）**：选择官方 Challenge 或自主命题，完成题目、科学问题、数据来源与方法备案；提交后由组委会确认，支持换题申请
3. **过程检查点（Day 3）**：提交代码进展、baseline 结果与 Agent 使用日志
4. **Research Package 提交（Day 7）**：九项提交物；支持站内上传或外链（如 Git 仓库），同类型重复提交自动记为更高版本
5. **评审与结果公示**：按 7 个维度评分（总分 100），按本科生组 / 研究生组公示
6. **孵化支持**：获奖团队获得 4 至 8 周项目孵化
