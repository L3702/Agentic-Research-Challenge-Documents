各赛道均强调真实数据、问题价值、证据与可复现；部分赛道偏好证明推导与算法实现，部分鼓励工程落地与实验证据。

## 自主命题说明

选择自主命题的团队，选题备案需说明：

1. **题目与科学问题**：预期回答什么问题
2. **数据来源**：公开数据或自建数据，说明获取与许可
3. **问题边界**：研究范围与不做的事
4. **最低验证要求**：至少完成什么实验 / 证据才算完成
