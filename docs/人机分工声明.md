# 人机分工声明

> **用途**：Research Package 第 8 项材料
> **对应论文**：央行书面沟通影响收益还是波动？——来自 102 期《货币政策执行报告》文本情绪的证据
> **声明时间**：2026-11-16（比赛第 1 天）

---

## 一、声明摘要

本项目由三名本科生组成的团队完成，在研究过程中使用了具备代码执行与文本处理能力的 AI 助手（DeepSeek Harness 环境下的科研助手）。总体分工原则是：**人类确定研究方向与判断标准，AI 承担数据处理、代码实现、文献核验与初稿撰写，所有输出由人类复核并承担最终责任**。

AI 未参与以下三类判断：研究价值的判断、结论可靠性的判断、以及对外提交内容的最终决定。这三类判断由团队作出，文责由团队承担。

## 三、AI 承担的工作

| 环节 | AI 的具体工作 |
|---|---|
| 选题评估 | 依据团队提供的数据与文献索引，指出题目不可直接检验之处，提出三条可选路线并比较优劣 |
| 数据审计 | 编写审计脚本，发现季度收益计算中的三处静默错误（空季度被计为 0、字符串季度无法排序、事件窗用自然日推进），并给出修复方案 |
| 代码实现 | 编写 10 个数据处理与估计脚本（文本抽取、情绪度量、事件表、面板构建、回归、校验） |
| 文本处理 | 解决 PDF 子集字体与压缩对象流的解析问题，实现政策指引段与宏观回顾段的自动切分 |
| 文献核验 | 阅读姜富伟等（2021）PDF 正文，核对周阳、綦岚鑫（2024）等文献的出处；逐条核验 19 条参考文献 |
| 计量分析 | 完成 H1 的估计与稳健性检验，包括断点检验、影响点检验与 500 次置换检验 |
| 论文起草 | 起草摘要、第 1–6 章正文与 9 张表格的 LaTeX 源码 |
| 制图 | 生成 5 张配图（情绪走势、散点、分位、断点、稳健性），并插入论文对应位置 |
| 政策数据核验 | 按央行官网原文核验降准、LPR、逆回购记录，订正 6 行，编制季度控制变量 |
| 复现包 | 编写 `verify_reproduction.py`（16 项自动校验）与可复现说明 |

## 四、人类承担的工作

| 环节 | 团队的具体工作 |
|---|---|
| 数据获取 | 从人民银行官网逐期下载 102 份报告 PDF；用 akshare 接口获取 37 个行业指数日行情；整理发布日元数据 |
| 词典获取 | 提供姜富伟词典文件；确认其引用要求 |
| 方向决策 | 确认采用"事件窗 + 分段度量"的路线；否决了以 LLM 度量为主线的方案 |

| 数据判断 | 判断 2015Q4 报告因春节休市导致的窗口异常是否保留；确认 2003 年前后四期的处理方式 |

## 六、AI 未参与的事项

1. **研究价值的判断**。题目是否值得做、结论是否有意义，由团队讨论后决定。
2. **数据合规性的判断**。数据来源是否允许使用、引用是否规范，由团队确认。
3. **结论可靠性的最终判断**。AI 提供了统计检验，但"这个结果能否支撑论文的主张"由团队判断。
4. **对外提交的决定**。提交哪些材料、如何表述贡献，由团队决定。
