## 二、代码改了什么（三处）

### 1. 先算收益，再切窗口

```python
# 错的：切片后 pct_change，首日变 NaN
df = df[df.index >= '2014-01-01']
df['daily_ret'] = df['收盘'].pct_change()

# 对的：在完整序列上算
df = df.set_index('日期').sort_index()
df['daily_ret'] = df['收盘'].pct_change()
```

### 2. 用"完整季度"判据，替代 `dropna()` + `!= 0` + 硬编码

```python
complete = (n_days >= 40) & (gap_to_quarter_end <= 5)
```

这三个条件一次解决：2014Q1（27 天）、2026Q4（24 天）、以及未来任何残缺季度。
**关键点**：绝不能用 `ret != 0` 剔除空季度——它会静默删掉真实的零收益季度。

### 3. 只保留"28 个行业都完整"的季度

申万 2014 版分类于 **2014-02-21** 生效，12 个行业在此之前的指数不存在。
所以 2014Q1 是"16 个行业 58 天 + 12 个行业 27 天"的混合季度，横截面不可比，**整季剔除**。

### 变量字典

| `quarter` | str | 日历年季，`YYYYQn` | — | 字典序 = 时间序，可直接排序 |

> `ret_ex` **不是**"战胜市场"的收益。基准是这 28 个行业的等权平均，且包含该行业自身。
> 做含季度固定效应的面板回归没问题；但不要用它论证"某些行业长期跑赢"。

## 四、必须写进论文的一段口径说明（关于 801950 煤炭）

> 本研究的行业口径为申万一级行业，共 28 个，样本期 2014Q2–2026Q3。
> 其中能源行业的代理变量为**煤炭（801950）**。需要说明的是：在申万 2014 版分类下，
> 煤炭属于采掘（801020）之下的二级行业，2021 年改版后升为一级行业并被回溯至 2014-02-21；
> 而石油石化（801960）仅有 2021-12 之后的数据。因此本样本的能源口径**只含煤炭、不含石油石化**，
> 且 2014–2021 期间的行业划分为事后回填。作为稳健性检验，本文另报告**剔除煤炭、使用 27 个行业**的结果。

（数据事实：煤炭与旧采掘在 1893 个共同交易日上的日收益相关系数为 **0.816**——高度相关但不等价。）
