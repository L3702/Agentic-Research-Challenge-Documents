### 两套词典怎么用

| 词典 | 规模 | 用途 |
|---|---|---|
| **姜富伟词典**（`data\external\姜富伟词典.xlsx`） | 积极 3338 / 消极 5890 | **主结果必须用它**——只有这样才和姜富伟（2021）可比，H1 复现才有意义 |

## 第 4 步：推到 develop（两种方法，选一种）

> ⚠️ **绝对不要在你项目的文件夹里敲 `git add .`**
> `data/raw/` 有 89.7MB（102 份 PDF + 37 个行情文件），一提交仓库会从 260MB 涨到 350MB+。
> 你的 `.gitignore` 没有忽略 `data/`，这个坑是真的会踩。

### 方法 A：网页上传（30 秒，最省事）✅ 推荐

1. 打开 https://github.com/L3702/Agentic-Research-Challenge-Documents
2. 左上角把分支从 `main` 切到 **`develop`**（**不要提交到 main**）
3. 点进 `data/processed/` → 右上 **Add file → Upload files** → 拖入 `sentiment.csv` → 底部 **Commit changes**
4. 再点进 `data/external/` → 同样上传 `mpr_sentiment_dict.csv`（如果这个目录不存在，就在根目录新建 `data/external` 路径会自动创建）
5. 再点进 `src/data/` → 上传 `build_sentiment.py`

一共 3 次提交，3 个文件。

### 方法 B：命令行（你已经装了 git）

```powershell
# 1) 克隆一份干净的副本（约 100MB，等 1-3 分钟）
cd $env:TEMP
git clone -b develop https://github.com/L3702/Agentic-Research-Challenge-Documents.git repo-dev
cd repo-dev

# 2) 把三个文件复制进去（路径按你实际的项目位置改）
$proj = "C:\Users\hzn97\Desktop\Agentic_Research_Challenge"
Copy-Item "$proj\data\processed\sentiment.csv"        "data\processed\" -Force
Copy-Item "$proj\src\data\build_sentiment.py"         "src\data\"     -Force
Copy-Item "$proj\data\external\mpr_sentiment_dict.csv" "data\external\" -Force
New-Item -ItemType Directory -Force -Path "data\external" | Out-Null

# 3) 只提交这三个文件（注意：不要用 git add .）
git add data/processed/sentiment.csv src/data/build_sentiment.py data/external/mpr_sentiment_dict.csv
git commit -m "feat(data): 102 期 MPR 情绪序列（P/R 分段）+ MPR 领域词典"
git push origin develop
```

**看到什么算成功**：最后一行出现 `develop -> develop`，然后去网页刷新 develop 分支，能看到 `sentiment.csv`。

> 第一次 push 会弹窗要求登录 GitHub（浏览器授权），正常走完即可。

## 附录：常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| `python` 不是内部或外部命令 | Python 没进 PATH | 用 `py` 代替 `python` 试试 |
| 终端乱码 | 编码问题 | 先运行 `chcp 65001` |
| 行数只有 69 | 用了 PDF 兜底解析 | 说明 `mpr_text` 没复制成功，回第 1.2 步 |
| 某期 `status=check` | 该期标题写法特殊 | 把期次发我，我加规则 |
| `git push` 报 403 | 没登录 | 按提示浏览器授权，或改用网页上传 |
