## 一、姜富伟等（2021）原文核查结论（✅ 已读 PDF 正文）

> 来源：`央行货币政策报告文本信息、宏观经济与股票市场_姜富伟.pdf`（《金融研究》2021 年第 6 期）
> 说明：PDF 的**数字字体**未能抽取，故样本区间年份、具体系数无法引用；下列均为正文文字可核实的内容。

| 问题 | 原文事实 |
|---|---|
| 被解释变量 | **四个股票指数**：上证综指、深证成指、沪深 300、中证 500 的**日度对数收益率**，涵盖大市/大盘/中小盘 |
| 是否做行业层面 | **完全没有**。全文未出现"行业"二字，也没有任何横截面分组 |
| 文本指标 | 三个维度：文本**情绪**（中文分词 + 情绪词典）、文本**相似度**、文本**可读性**（平均句子长度等） |
| 计量模型 | GARCH 类模型（均值方程 + 方差方程） |
| 控制变量 | **货币供应量增速** 与 **货币政策操作** 两个代理变量 |
| 事件窗口 | 报告发布后 **一个交易日** |
| 核心发现 1 | 情绪上升 → 指数收益率显著上升；相似度上升 → 波动率下降；可读性不显著 |
| 核心发现 2 | **把情绪拆成"宏观经济基本面部分"与"央行货币政策指引部分"：只有指引部分显著，基本面部分不显著**。作者解释：报告里的宏观数据在发布前已公布，市场已经反应过 |

**一句话**：姜富伟做的是"**一份报告 → 一个市场**"，用四个宽基指数代表市场；**行业横截面是空白**。

## 二、这对我们的设计意味着什么（三处必须修正）

### 修正 1：不能再把"控制政策操作后文本仍显著"当作创新

姜富伟**已经**在均值方程里控制了货币供应量增速和货币政策操作，文本情绪依然显著。

→ 我们**必须**做这个控制（否则审稿人第一句就问），但它只是**控制变量**，不是卖点。

### 修正 2：文内分段（指引 vs 基本面）是"必须复现的基准"，不是"我们的发现"

我上一轮把它称为"天然安慰剂/差异化武器"，**这个说法要收回**。姜富伟已经做完并写进结论。

→ 它的正确用途变成**测度可信度检验**：
- 如果我们的 P 段（指引）显著、R 段（基本面）不显著 → 说明我们的情绪测度与顶刊一致，**可信**；
- 如果反过来 → 说明我们的分段或词典有问题，**先排查再往下走**。

这是一个能写进论文的方法论细节，但不能宣称是贡献。

### 修正 3：唯一的真空白 = 行业横截面 + 行业暴露度

| 已有 | 我们做 |
|---|---|
| 市场层面（四个宽基指数） | 行业层面（28 个申万一级） |
| 平均效应 | **差异化效应**：谁更敏感、为什么 |
| 无暴露度 | **行业利率敏感度（久期）** 作为调节变量 |

**收敛后的研究问题（第二版）**：

> 同一份 MPR 文本情绪，为什么对不同行业的影响不同？这种差异能否由行业对利率的敏感度（久期）解释？

**假设表**：

| 编号 | 表述 | 与文献的关系 | 证伪条件 |
|---|---|---|---|
| H1（基准复现） | P 段（指引）情绪 → 行业超额收益为正；R 段（基本面）不显著 | 复现姜富伟，检验测度可信度 | H1 不成立 → 测度有问题，先修 |
| H2（核心增量） | 情绪效应随行业久期递增（高久期行业反应更强） | 无文献做过 | 交互项不显著或反向 |
| H3（非对称） | 宽松与紧缩方向效应不同 | 王宇伟等（2025）提示，待验证 | 完全对称 |
| H4（度量稳健） | 词典法与 LLM 情绪给出一致结论 | 稳健性 | 结论由度量方式驱动 |

## 三、文本可得性诊断：这是一个硬约束，必须现在就处理

我写了 `src/data/pdf_to_text.py`（纯标准库、无依赖），对 102 份 MPR PDF 逐份测试，结果：

| 判定 | 份数 | 年份分布 |
|---|---|---|
| ✅ 可抽取 | **69** | 2001–2010 大部分、2018Q4 之后几乎全部 |
| ❌ 抽不出 | **33** | **2011Q1–2018Q3 几乎整段缺失**，另加 2003Q3、2005Q4、2008Q1、2010Q3、2022Q3 |

完整清单见 `docs/文本可得性诊断.md` 与 `data/processed/text_availability.csv`。

**连续可用区段**：

| 区段 | 期数 | 对应行业数据 |
|---|---|---|
| 2001Q1–2010Q4 | **36 期**（缺 2003Q3、2005Q4、2008Q1、2010Q3） | 16 个连续行业 |
| **2018Q4–2026Q2** | **29 期**（缺 2022Q3） | 全部 28 个行业 |

**这是路线 A 最大的现实约束**：事件数只有 29（近段）或 36（早段），不是 102。

### 三条补救路径（按性价比排序）

| 路径 | 做法 | 成本 | 建议 |
|---|---|---|---|
| **A. WPS/Office OCR** | 用 WPS 的"PDF 转文字/OCR"批量处理那 33 份（你机器上装了 WPS） | 33 份 × 约 1 分钟 + 校对 | **推荐**，能补回 2011–2018 整段 |
| B. 换数据源 | 从 Wind/CSMAR/国研网取报告全文（HTML/TXT） | 需数据库权限 | 有权限就用，最干净 |
| C. 承认缺口 | 只用两个可用区段做"双样本"设计 | 0 | 立刻可做，但样本小 |

> 我试过直接抓央行官网 HTML：**页面只有 PDF 附件链接，没有正文**（2001Q1 与 2015Q1 都是）。所以路径 B 只能靠商业数据库。

### `event_map.csv` 里三个必须先知道的事实

1. **6 期报告的发布日不是交易日**，已自动顺延到下一个交易日：
   2010Q4、2013Q4、2015Q4、2019Q3、2020Q1、2022Q1。
2. **2015Q4 最特殊**：2016-02-06（周六）发布，紧接着春节休市，**t0 = 2016-02-15，发布后 9 天才有第一个交易日**。
   这 9 天里积累的国内外信息会全部砸在开盘日，这期的 CAR 不可与其他期直接比较。
3. **10 期报告的"发布→t+5"跨越 ≥9 个自然日**（春节/国庆），建议主回归剔除或单独标注。

关于"发布当日算不算"：`mpr_meta.csv` 的 `pub_time` **102 行全为空**，无法判断盘中还是盘后。MPR 通常在收盘后发布，所以**主表建议用 [t1, t5]**，稳健性用 [t0, t5]。

## 五、接下来 3 天怎么推进（可按人力压缩）

### 第 1 优先：把文本补齐（半天，决定样本量）

1. 用 WPS 把 `docs/文本可得性诊断.md` 里 33 份"CID/SCAN"的 PDF 转成 txt，放进 `data/processed/text/`
2. 重跑 `python src/data/diagnose_text_availability.py`，目标 **≥95 份 OK**
3. 若补不齐，**立刻决定**用"双样本"（见 §6 决策点）

### 第 2 优先：造情绪序列（1 天）

1. `python src/data/pdf_to_text.py data/raw/mpr/xxx.pdf <输出目录>` 批量抽全部文本
2. **P/R 分段**：P 段 = "下一阶段主要政策思路"（2015 年后改称"货币政策趋势"）之后的正文；
   R 段 = 其之前的部分。102 份逐份打印分段边界，人工扫一遍（约 40 分钟）
3. **词典法情绪**：先用姜富伟同款思路（中文分词 + 情绪词典），这样 H1 才有可能复现成功
4. 输出 `data/processed/sentiment.csv`：`period, sent_P, sent_R, n_char_P, n_char_R`

### 第 3 优先：事件研究基线（1 天）

1. 用 `event_map.csv` 的市场模型估参数 → 算 CAR[-1,+5]、CAR[t1,t5]
2. 回归：`CAR ~ sent_P`，**聚类到事件**（102 个事件）
3. 先跑 H1（复现），**这一步通过才说明测度可信**，再往下做 H2

> 顺序很重要：**先复现文献、再做增量**。如果一上来就做交互项，出了问题分不清是"行业没差异"还是"情绪测错了"。

## 七、路线 A 的最终形态（写论文时照着搭）

```
       MPR 文本（102 期 → 可用的 ~69 期）
                 │
        ┌────────┴────────┐
     P 段（政策指引）    R 段（宏观基本面）
        │                  │
        │  ← H1：P 显著、R 不显著（复现姜富伟，检验测度）
        │
   行业日度超额收益（28 行业 / 16 行业）
        │
   CAR[t1,t5]  ← 市场模型，估计窗 [-120,-11]
        │
   ┌────┴─────────────────────┐
   │ H2：CAR ~ sent_P × 久期   │  ← 核心增量：行业横截面
   └────┬─────────────────────┘
        │
   H3 非对称（宽松 vs 紧缩） · H4 词典 vs LLM
        │
   稳健性：换窗口 / 剔除长假事件 / 换基准 / 控制政策操作
```

**一句话**：**用姜富伟证明我们没测错，用行业横截面证明我们比他多走了一步。**
