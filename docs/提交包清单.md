## 四、怎么用这个包

**看论文**：直接打开 `论文_完整稿.pdf`。

**改论文**：编辑 `docs/ch*.tex`，然后

```powershell
pip install -r requirements.txt
python build_paper.py                 # 生成 docx
```

再用 LibreOffice 或 Word 导出 PDF。注意 `build_paper.py` 会按 `docs/figures/` 里的图自动插入配图。

**复核数据**：

```powershell
python src/data/verify_reproduction.py    # 16 项自动校验
```

**重跑全流程**：见 `docs/可复现说明.md`，五步约 10 分钟。

**重画图**：

```powershell
python src/data/make_figures.py           # 输出到 docs/figures/
```
