## 一、表一：存款准备金率调整

### 为什么要这张表
2008 年之后，降准取代基准利率成为最主要的宽松工具。论文的波动效应在 2008 年前后最敏感，若不同时控制降准，"情绪效应"可能只是"降准效应"的代理。

### 表头（严格按这个顺序，共 11 列）

| 列名 | 类型 | 说明 | 示例 |
|---|---|---|---|
| `seq` | 整数 | 序号，从 1 开始 | `1` |
| `announce_date` | 日期 | **公告日**，格式 `YYYY-MM-DD` | `2008-11-26` |
| `effective_date` | 日期 | 生效日，若与公告日相同则填同一个 | `2008-12-05` |
| `direction` | 文本 | 只能是 `降准` 或 `升准` | `降准` |
| `institution` | 文本 | `大型金融机构` / `中小型金融机构` / `全部` | `大型金融机构` |
| `rate_before` | 数值 | 调整前准备金率，单位 %，保留两位小数 | `17.00` |
| `rate_after` | 数值 | 调整后准备金率，单位 %，保留两位小数 | `16.00` |
| `change_pp` | 数值 | 变动幅度，**单位百分点，降为负** | `-1.00` |
| `targeted` | 0/1 | 是否定向降准，1=定向，0=全面 | `0` |
| `source` | 文本 | 公告标题或 URL | 见下 |
| `note` | 文本 | 补充说明，如"置换 MLF""覆盖所有存款类金融机构" | `置换到期 MLF` |

### 填表规则

1. **一行 = 一次调整动作**。同一天对大型、中小型机构分别下调，记**两行**（`institution` 不同）。
2. **公告日与生效日都要填**。市场对公告日反应，回归用公告日；生效日留作核对。
3. **幅度单位是百分点，不是百分比**。从 17.00% 降到 16.00%，`change_pp` 填 `-1.00`，不是 `-5.88`。
4. **定向降准照收，但 `targeted` 标 1**。是否纳入回归由我决定，你先如实记录。
5. **不要合并同一天的多项操作**。比如某日既降准又降息，降准记这张表，降息记表三。
6. `source` 至少要有公告标题；有链接更好。格式示例：
   `中国人民银行决定下调存款准备金率（2008-11-26）` 或贴 `pbc.gov.cn` 的具体页面地址。

### 数据从哪来（按可靠程度排序）

1. **人民银行官网** → 货币政策 → 货币政策工具 → 存款准备金（有历史数据页）
2. **历年《货币政策执行报告》的专栏**。每年的报告里有一篇专栏汇总当年准备金率调整，是最可靠的交叉验证来源
3. 人民银行"新闻发布"栏目按日期翻，用关键词"下调存款准备金率""上调存款准备金率"

### 不要用的来源
- 百度百科、互动百科
- 东方财富、同花顺等行情站的"宏观数据"页
- 任何个人博客、公众号汇总

这些来源的日期和幅度经常有错，而且改了几手已经无法追溯。

## 二、表二：LPR 报价变动

### 为什么要这张表
2019 年 8 月贷款利率换锚到 LPR，此后降息通过 LPR 体现。基准利率在 2015 年 10 月后冻结，若不用 LPR，2019 年之后的宽松就完全测不到。

### 表头（8 列）

| 列名 | 类型 | 说明 | 示例 |
|---|---|---|---|
| `seq` | 整数 | 序号 | `1` |
| `date` | 日期 | 报价日 `YYYY-MM-DD` | `2019-08-20` |
| `tenor` | 文本 | `1年期` 或 `5年期以上` | `1年期` |
| `rate_before` | 数值 | 上期报价 % | `4.31` |
| `rate_after` | 数值 | 本期报价 % | `4.25` |
| `change_pp` | 数值 | 变动，降为负 | `-0.06` |
| `source` | 文本 | 来源 | `全国银行间同业拆借中心` |
| `note` | 文本 | 备注 | `LPR 改革后首次报价` |

### 填表规则

1. **只记有变动的月份**。没变的不记。
2. **1 年期与 5 年期以上分开记**（`tenor` 区分），两行。
3. **2019-08-20 是改革后首次报价**，`rate_before` 可填旧口径 LPR 4.31，`note` 注明"改革后首次"。
4. 首次报价之前（2019-08 以前）的旧 LPR 不要收，口径不同。

### 数据从哪来
1. 全国银行间同业拆借中心（chinamoney）→ 贷款市场报价利率（LPR）→ 历史数据
2. 人民银行官网 → 货币政策 → 贷款市场报价利率

## 三、表三：7 天逆回购利率调整

### 为什么要这张表
2015 年之后，7 天逆回购利率成为短期政策利率的锚。降息常常先动它。

### 表头（7 列）

| 列名 | 类型 | 说明 | 示例 |
|---|---|---|---|
| `seq` | 整数 | 序号 | `1` |
| `date` | 日期 | 调整日 `YYYY-MM-DD` | `2015-04-07` |
| `rate_before` | 数值 | 调整前 % | `3.65` |
| `rate_after` | 数值 | 调整后 % | `3.55` |
| `change_pp` | 数值 | 变动，降为负 | `-0.10` |
| `source` | 文本 | 公开市场业务交易公告 | `公开市场业务交易公告 2015 年第 27 号` |
| `note` | 文本 | 备注 | |

### 填表规则

1. **只收 7 天品种**。14 天、28 天不收（品种变了，序列不连续）。
2. 同一天多次操作（如同时有 7 天和 14 天），只记 7 天那一笔。
3. 2015 年之前 7 天逆回购不连续，若发现 2012–2014 年有零星操作，可收但 `note` 注明"非常态化操作"。

### 数据从哪来
人民银行官网 → 公开市场业务 → 公开市场业务交易公告（逐条翻，或用站内搜索"逆回购 利率"）

## 四、通用规则（三张表都适用）

### 日期口径
- **一律用公告日**（不是生效日、不是媒体发稿日）。
- 公告日与新闻稿日期不一致时，以央行官网原文日期为准，并在 `note` 说明。

### 数值口径
- 全部用**百分点**，保留两位小数。
- 降为负、升为正。`change_pp = rate_after − rate_before`，必须能对上，不能对上的说明原因。

### 缺失与不确定
- 查不到前值的，`rate_before` 留空，`note` 写"前值待核"。
- 完全无法确认的，**不要写进表**，在说明文档的"未收录清单"里列出来，写清卡在哪一步。

### 格式
- UTF-8 编码，逗号分隔，**第一行是表头**。
- 日期统一 `YYYY-MM-DD`，不要用 `2008/11/26` 或 `20081126`。
- 不要合并单元格、不要加粗、不要加多余的空列。

## 七、我拿到之后怎么用（供你理解为什么这么要）

- 用 `announce_date` 判断事件落在哪个季度（`period`）；
- 用 `change_pp` 汇总成三个控制变量：季度降准幅度、季度 LPR 变动、季度逆回购变动；
- 三者量纲不同（降准动辄 0.5，逆回购多为 0.05），回归时会分别标准化，**不会直接相加**；
- 定向降准（`targeted=1`）先做稳健性，看纳入与剔除是否改变结论；
- 最终合并成 `period + n_cut + delta_rrr + delta_lpr + delta_omo` 一张宽表，接入现有回归。
