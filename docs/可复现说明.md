# 可复现说明

> **用途**：Research Package 第 7 项材料
> **对应论文**：央行书面沟通影响收益还是波动？——来自 102 期《货币政策执行报告》文本情绪的证据
> **一句话**：从 102 份原始 PDF 到论文表 5.6，只需运行 4 个脚本、约 10 分钟；已有产物可用一条命令校验。

---

## 一、运行环境

| 项目 | 要求 | 说明 |
|---|---|---|
| 操作系统 | Windows / macOS / Linux | 本文在 Windows 11 上完成 |
| Python | 3.10 及以上 | 在 3.12 下验证通过 |
| 依赖 | 见 `requirements.txt` | 仅 4 个包，无需 GPU |
| 网络 | **不需要** | 数据已全部落盘，脚本不访问外部接口 |
| 运行时间 | 全流程约 10 分钟 | 其中文本解析占绝大部分 |

`requirements.txt`：

```
pandas>=2.0
numpy>=1.24
openpyxl>=3.1
pypdf>=3.9
```

安装：

```powershell
pip install -r requirements.txt
```

> 四个包的用途：`pandas`/`numpy` 做数据处理与回归，`openpyxl` 读情感词典（xlsx），
> `pypdf` 抽取 PDF 文本。回归部分未使用 statsmodels 或 linearmodels，OLS 与
> Newey--West 标准误由 numpy 直接实现，故依赖极少。

## 三、复现步骤

以下命令均在项目根目录执行。若 `data/raw/` 与 `data/external/` 已就位，可直接从第 2 步开始。

### 第 1 步：准备原始数据（仅在缺失时需要）

1. 把 102 份 MPR PDF 放入 `data/raw/mpr/`，文件名格式 `YYYYQn.pdf`；
2. 把 37 份行业行情 CSV 放入 `data/raw/sw/`，文件名格式 `801010.csv`；
3. 把姜富伟词典放入 `data/external/姜富伟词典.xlsx`。

> 词典来源：`https://github.com/MengLingchao/Chinese_financial_sentiment_dictionary`，
> 文件名"中文金融情感词典_姜富伟等(2020).xlsx"。该词典随附说明页，允许学术使用，
> 需引用 Jiang et al.（2019）与姜富伟等（2020）。

### 第 2 步：构建情绪序列（约 3–5 分钟）

```powershell
python src/data/build_sentiment.py --dict "data\external\姜富伟词典.xlsx"
```

**预期输出**：

```
[词典] data\external\姜富伟词典.xlsx → 积极 3190 / 消极 5604
[文本] ... 后端 = pypdf
[完成] 写出 data/processed/sentiment.csv（102 行）与 docs/情绪序列诊断.md
       分段成功 98/102；R-P 相关 0.375
       需复核期次：2003Q1, 2003Q2, 2003Q3, 2004Q1
```

> 词典条数由 3338/5890 降到 3190/5604，是因为脚本剔除了 4 个单字积极词、17 个单字
> 消极词并去重（单字用子串匹配会误命中），属预期行为，见论文 3.1 节。

### 第 3 步：构建事件窗市场收益（约 5 秒）


**预期输出**：

## 五、校验未通过时怎么排查

`verify_reproduction.py` 的每一项都会打印实际值与预期值，按以下顺序排查：

| 现象 | 可能原因 | 处理 |
|---|---|---|
| `sentiment.csv` 行数不是 102 | `data/raw/mpr/` 中 PDF 数量不对 | 检查文件名是否为 `YYYYQn.pdf` |
| `tone_P` 非缺失期数不是 99 | 分段规则未命中，或文本抽取结果不同 | 查看 `docs/情绪序列诊断.md` 中"需人工复核的期次" |
| R–P 相关偏离 0.375（如 0.77） | 分段未生效，P 段误取成了全文 | 检查正则锚点是否被改 |
| 系数符号对但数值偏差 10% 以上 | 词典不同或小数字体抽取差异 | 确认 `--dict` 指向的是姜富伟词典 |
| `h1_coef.csv` 找不到模型 | 修改过 `run_h1.py` 的模型名 | 恢复原始命名 |

## 六、已知问题与处理

**① 2003–2004 年四期的分段情况。** 2003Q2、2003Q3、2004Q1 的报告章节写法与其他年份不同（"预测和展望"/"预测与展望"），当前锚点规则未覆盖，这三期不生成 P 段情绪，回归自动剔除；2003Q1 虽匹配到锚点，但 P 段占比达 93.6\%，经复核系排版错位，该期保留在主回归中，并在 `run_h1.py` 的影响点检验中报告剔除后的结果（振幅 $-25.5$，$t=-2.24$；断点交互 $-81.2$，$t=-2.38$），结论不变。

> 需要说明的是，脚本中保留这一规则是为了与论文表 5.2–5.6 所用数据完全对应。若在 `P_HEAD_PATTERNS` 中补入 `预测[与和]展望`，这三期即可正常分段，但样本会由 99 期扩至 101 期，全部系数需重新估计，故本文未作此处理，并在论文 3.1 节如实说明这四期的情况。

**② pypdf 版本差异。** 不同版本的 pypdf 对同一 PDF 的断行处理略有差别，可能使个别期次的情绪值在小数点后第三位变动。系数与显著性不受影响，但若 `verify_reproduction.py` 报出轻微偏差，属正常范围。

**③ Windows 控制台乱码。** 脚本输出含中文，部分终端编码设置下会显示为乱码，**不影响写入的 CSV 文件**。可在运行前执行 `chcp 65001`。

**④ 词典获取。** `data/external/姜富伟词典.xlsx` 来自公开仓库（见第 1 步），使用时须遵守其引用要求。若无法获取，可改用 `mpr_sentiment_dict.csv` 复现替代词典口径的结果。

**⑤ 市场组合的构造。** 市场收益由 16 个行业等权组合计算，未使用沪深 300。原因见论文 3.2 节：未能取得覆盖 2001 年以来的沪深 300 日线。若后续补齐该数据，只需在 `build_market_events.py` 中增加一个指数来源即可，其余脚本无需改动。
